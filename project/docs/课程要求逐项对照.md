# 课程要求与当前交付对照

依据：[课程设计要求](课程设计要求.md)。复核：2026-11-15，0.4.0 / schema v4。下表中的测速、流量实测发生于 2026-10-17；本次截图重新读取当前 DEV 页面及其历史记录。

| 原要求 | 已实现与验证 | 保留的差距 |
|---|---|---|
| 故障：连通性等检测与诊断 | ping/接口连续异常、告警确认/恢复、依据样本的诊断分类及关联接口；真实查询和确认已验 | 自然故障发生/恢复的现场案例仍缺；诊断不直接确认根因 |
| 配置：IP、拓扑等探测 | 新增 ipAddrTable 读 IP/掩码/接口与历史记录；DEV 四候选共 27 条地址；浏览器显示采样子网图与文档关系；快照能比较地址 | 物理身份/实际直连未独立确认；不同真实配置的差异仍待出现 |
| 性能：带宽、延迟等测量 | 真实 RTT/丢包/接口速率，新增稳定采样验证；网页真实 iperf3 一次成功，约 9.94 Mbit/s | 限速结果不代表最大容量；host-3 未配专用 SSH 授权 |
| 计费：网元间流量统计 | 接口方向总量/覆盖率/CSV、设备与窗口内子网归属；独立按网元对统计成功测试传输，真实接收 2,486,216 byte | 全部业务的主机对流量仍需流记录支持；应确认教师是否接受当前粒度 |
| 安全：安全风险检测 | 新增被动 TCP 多端口与持续探测规则、来源/目标证据、监听心跳与缺口；保留默认 SNMP、服务基线、潜在 Telnet、高利用率规则 | 扫描监测仅覆盖指定本机地址，来源 IP 不等于确认攻击者；不确认漏洞/入侵，全网范围和真实修复仍待补齐 |

系统已在 DEV 部署，并有真实采集到 SQLite/API/网页、网页任务到统计的验证记录。2026-11-15 本地完整 Python 回归 **109 项通过**，4 组前端检查通过，包括新增的请求超时与流量查询并发回归。

本轮发现并修正两项网页问题：读取请求超过 30 秒、写请求超过 75 秒时明确提示并结束等待（写操作不自动重试）；重新统计流量时清空旧表，过期请求不得覆盖新时间窗的结果或 CSV。写请求保留更长等待，是因为手动采集需要等待完整轮次。静态文件已备份后更新到 DEV。

本轮已读取到持续更新的成功采集：三个测试主机最近一轮 ping 均为 0% 丢包；接口历史指标已超过 238 万条。当前故障记录仍需区分虚拟网桥异常与真实业务中断。数据保留、归档和查询耗时应纳入后续计划。新电脑接入已恢复，但 WARP 仍出现偶发断连，不能据此宣称网络接入长期稳定。

周期采集已启用：每轮结束等待 15 秒，再执行下一轮；实际采样间隔还包含采集耗时，不能写成“每 15 秒采样一次”。2026-10-17 曾验证连续自动 run 15/16 成功、采集耗时约 25～28 秒，并清理测试端口；这些是历史实测记录，不能替代当前运行耗时或端口状态的检查。

详细操作、截图和真实数值见[新增功能说明](差距补齐与验收说明.md)，API 与数据边界见[接口合同](../接口与数据合同.md)。首次开题材料继续保留历史计划，不随实现结果重写。

被动扫描的规则、覆盖与验证单独见[被动扫描监测](被动扫描监测.md)。原 109 项回归及中期汇报截图属于新增监听功能前的历史检查，不作为当前版本的全部验证结论。

被动监听已在 DEV 上线，当前覆盖其三个本机地址；已记录 `192.168.3.1 → 192.168.0.100` 的真实多端口探测，并明确标为内部来源、非已确认攻击者。当前版本完整 Python 回归 120 项通过，发布包隔离冒烟及真实桌面/手机页面检查通过；具体时间与运行限制见被动扫描监测说明。
