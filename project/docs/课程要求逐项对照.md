# 课程要求与当前交付对照

依据：[课程设计要求](课程设计要求.md)。更新：2026-10-17，0.3.0 / schema v3。

| 原要求 | 已实现与验证 | 保留的差距 |
|---|---|---|
| 故障：连通性等检测与诊断 | ping/接口连续异常、告警确认/恢复、依据样本的诊断分类及关联接口；真实查询和确认已验 | 自然故障发生/恢复的现场案例仍缺；诊断不直接确认根因 |
| 配置：IP、拓扑等探测 | 新增 ipAddrTable 读 IP/掩码/接口与历史记录；DEV 四候选共 27 条地址；浏览器显示采样子网图与文档关系；快照能比较地址 | 物理身份/实际直连未独立确认；不同真实配置的差异仍待出现 |
| 性能：带宽、延迟等测量 | 真实 RTT/丢包/接口速率，新增稳定采样验证；网页真实 iperf3 一次成功，约 9.94 Mbit/s | 限速结果不代表最大容量；host-3 未配专用 SSH 授权 |
| 计费：网元间流量统计 | 接口方向总量/覆盖率/CSV、设备与窗口内子网归属；独立按网元对统计成功测试传输，真实接收 2,486,216 byte | 全部业务的主机对流量仍需流记录支持；应确认教师是否接受当前粒度 |
| 安全：安全风险检测 | 默认 SNMP 访问、服务基线、潜在 Telnet、高利用率规则；DEV 形成四条配置风险，真实页面确认已验 | 不确认具体漏洞或攻击源；真实风险恢复待配置变化 |
