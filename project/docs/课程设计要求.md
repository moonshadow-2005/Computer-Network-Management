# 课程设计要求（去除访问凭据的整理版）

本文件依据教师《课程设计说明》和首次开题通知整理，保留任务、拓扑和协议条件。公网入口、账户、密码及实验授权由课程另行提供；细则以教师原件为准。

## 1. 必需功能

各组在独立试验网络中设计一个网络管理系统，包含以下五项功能；可以实现额外功能，额外功能可能加分。

| 功能 | 课程要求 |
|---|---|
| 故障管理 | 网元联网故障（连通性等）检测与诊断 |
| 配置管理 | 网元联网参数（IP 地址、拓扑等）探测 |
| 性能管理 | 网元联网性能（带宽、延迟等）测量 |
| 计费管理 | 网元间流量统计 |
| 安全管理 | 网络内安全风险（可能的安全漏洞、攻击源等）检测 |

## 2. 实验环境

- DEV 是入口点和开发主机，管理系统应部署于 DEV，其内网地址为 `192.168.0.100`。
- 三个子网为 `192.168.1.0/24`、`192.168.2.0/24`、`192.168.3.0/24`。
- 子网 1 有 `192.168.0.1` 和 `192.168.0.2` 两个连接地址；子网 2 对应 `192.168.0.5`，子网 3 对应 `192.168.0.8`。文档地址不能直接推断物理路由器数量。
- 内网测试主机为 `192.168.1.1`、`192.168.2.1`、`192.168.3.1`，课程开放 SSH 登录权限；测试用户无 root 权限且无外网访问，主机预装 `ping` 和 `iperf3`。
- 第 2 组入口使用 IPv6 SSH；这属于真实环境接入条件，本机样例不需要 IPv6。

文档逻辑拓扑：

```text
192.168.2.0/24                             192.168.3.0/24
      |                                         |
192.168.0.5                               192.168.0.8
      |                                         |
================ 中间网络（192.168.0.x）================
      |                    |                   |
192.168.0.100          192.168.0.1          192.168.0.2
     DEV                   \                   /
                            192.168.1.0/24
```

## 3. 协议与工具边界

路由器开放 SNMP v2c GET，未开启 SNMP SET 和 TRAP。可以借助 SNMP 实现网络管理，但不能据此假定所有表、所有 OID 或 GETNEXT/GETBULK 在每个目标上都可用；实际读取应记录成功、未知或失败。

三台内网测试主机预装工具不表示 iperf3 服务端常驻。吞吐量测试需要配对服务端和客户端，并清理测试进程。DEV 是否预装工具应另查，不能从内网主机条件推导。

## 4. 首次开题汇报要求

15 分钟以内，内容包括各功能的预期效果、方法和工具、组员分工与时间计划，以及希望交流的问题或支持。首次材料归档于[开题报告目录](../../开题报告/README.md)。组内讨论采用约 9～10 周的整体项目计划，不能当作教师已确认的最终截止日期。

## 5. 当前实现与要求的关系

本仓库实现和限制见[架构说明](架构与模块说明.md)。计费先实现接口方向流量统计，任意主机对归属和单价尚需额外条件；安全先实现服务基线与高利用率风险线索，不能据此宣称已完成漏洞验证或攻击源归因。课程对计费粒度、安全深度的最终口径仍需确认。

## 6. 课程列出的常用 OID

| OID名称 | 文本标识符 | 数字 OID | 描述 |
|---|---|---|---|
| 接口索引 | `ifIndex` | `.1.3.6.1.2.1.2.2.1.1` | 每个接口的唯一编号 |
| 接口描述 | `ifDescr` | `.1.3.6.1.2.1.2.2.1.2` | 接口的文本描述（如 `eth0`） |
| 管理状态 | `ifAdminStatus` | `.1.3.6.1.2.1.2.2.1.7` | 接口的预设状态（up/down） |
| 运行状态 | `ifOperStatus` | `.1.3.6.1.2.1.2.2.1.8` | 接口的实际操作状态 |
| 输入流量（入方向） | `ifHCInOctets` | `.1.3.6.1.2.1.31.1.1.1.6` | 接口接收的总字节数（高性能计数器，支持高速接口） |
| 输出流量（出方向） | `ifHCOutOctets` | `.1.3.6.1.2.1.31.1.1.1.10` | 接口发送的总字节数（高性能计数器） |
| 接口速率 | `ifHighSpeed` | `.1.3.6.1.2.1.31.1.1.1.15` | 接口当前带宽的估计值（单位：Mbps） |
| 输入错误包 | `ifInErrors` | `.1.3.6.1.2.1.2.2.1.14` | 入站错误数据包数 |
| 输出错误包 | `ifOutErrors` | `.1.3.6.1.2.1.2.2.1.20` | 出站错误数据包数 |
| IP路由表 | `ipRouteTable` | `.1.3.6.1.2.1.4.21` | IP路由表。经典路由表，因掩码表示问题已被标记为过时，但在许多设备上仍可使用。 |
| 路由目的地址 | `ipRouteDest` | `.1.3.6.1.2.1.4.21.1.1` | 索引。路由的目标网络地址。 |
| 出接口索引 | `ipRouteIfIndex` | `.1.3.6.1.2.1.4.21.1.2` | 数据包发出接口的索引号，对应 `ifTable` 中的接口。 |
| 下一跳地址 | `ipRouteNextHop` | `.1.3.6.1.2.1.4.21.1.7` | 数据包应被发送到的下一个路由器的IP地址。 |
| 路由类型 | `ipRouteType` | `.1.3.6.1.2.1.4.21.1.8` | 路由类型（例如：3=直连 `direct`，4=非直连 `indirect`）。 |
| 路由协议 | `ipRouteProto` | `.1.3.6.1.2.1.4.21.1.9` | 路由来源协议（例如：2=本地 `local`，3=网管 `netmgmt`，8=RIP, 13=OSPF, 14=BGP）。 |
| 路由掩码 | `ipRouteMask` | `.1.3.6.1.2.1.4.21.1.11` | 目标网络的子网掩码。 |
| CIDR路由表 | `ipCidrRouteTable` | `.1.3.6.1.2.1.4.24.4` | 现代路由表，支持CIDR无类别掩码 |
| CIDR路由目的地址 | `ipCidrRouteDest` | `.1.3.6.1.2.1.4.24.4.1.1` | 索引。路由的目标网络地址。 |

注：路由器均未开启SNMP TRAP和SNMP SET功能。
