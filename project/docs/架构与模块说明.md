# 架构与模块说明

## 数据如何流动

```text
SNMP v2c / ping / 指定 TCP 端口 / 受控 iperf3
                 ↓
       采集调度与五项管理逻辑
                 ↓
        SQLite 原始样本、指标、事件
                 ↓
          FastAPI /api/v1
                 ↓
         原生网页、趋势图和 CSV
```

单 worker 服务统一管理采集锁和任务端点互斥。后台轮询默认关闭；开启实时采集后可手动采集，间隔大于 0 时才周期运行。页面查询 SQLite，不直接向设备发送 SNMP。

## 代码职责

| 代码 | 作用 |
|---|---|
| `run.py` | 加载本机 `.env`，选择独立的样例或实验模式，启动 Uvicorn |
| `app/main.py` | API、统一响应、参数与令牌校验、静态页面 |
| `app/demo.py` | 幂等装载带 `sample` 标记的构造数据 |
| `app/core/config.py` | 运行配置、采样限制与开关 |
| `app/core/db.py` | SQLite schema、文档候选清单、迁移和备份 |
| `app/collectors/snmp.py` | 有界 SNMP v2c GET/GETBULK/GETNEXT；校验响应来源、community、请求编号和 OID |
| `app/collectors/ping.py` | 有限次数 ping、RTT/丢包解析与查询失败区分 |
| `app/service.py` | 登记目标的采集调度、单目标失败隔离、完整表保护 |
| `app/modules/fault_config.py` | 故障去重/恢复、接口状态、配置快照及差异 |
| `app/modules/perf_accounting.py` | 64 位计数差分、有效区间、速率/利用率和流量报表 |
| `app/modules/iperf_tasks.py` | 限时限速任务、远端就绪、取消、端点互斥和清理 |
| `app/modules/security.py` | 服务基线观测、风险状态、连续高利用率规则 |
| `app/web/` | 五功能页面、筛选、趋势图、管理操作和 CSV 链接 |
| `deploy/` | Linux 离线归档、摘要/路径校验、systemd 安装、更新和失败回退 |

## 计算与状态约定

- 累计字节和汇总量采用十进制字符串保存，避免 JavaScript 大整数精度丢失。
- 速率为 `8 × 字节差 / 实际秒数`；利用率还需可靠参考速率。
- 首样本、设备重启、计数器复位/不连续、非递增时间、采样间隔过长等区间不算正常速率或有效流量。
- 告警的 `active/recovered` 与确认时间独立；安全风险使用 `open/acknowledged/resolved`。
- SQLite 迁移前使用 Online Backup 创建私有备份，不支持的更高 schema 版本直接拒绝。
- GET 不要求管理令牌；POST 使用 `X-Admin-Token`，实时采集和主动测试另有开关。

API、字段、单位、时间窗和迁移细节见[接口与数据合同](../接口与数据合同.md)。

## 当前能力和限制

| 功能 | 当前实现 | 边界 |
|---|---|---|
| 故障 | ping/接口状态连续异常、证据、确认和恢复 | 超时或查询失败保留未知，不直接等同设备宕机 |
| 配置 | 接口/路由清单、只读快照差异、文档逻辑拓扑 | 地址尚不能直接归并为物理设备；真实差异需要另一份不同快照；不写设备配置 |
| 性能 | RTT、丢包、方向速率/利用率、受控 iperf3 任务 | 受控测试结果不是链路最大带宽；应用级 SSH 前置条件由部署者准备 |
| 计费 | 接口方向字节、覆盖率、缺口和 CSV | 尚不支持任意主机对归属、用户单价或真实资费账单 |
| 安全 | 指定端口基线和连续高利用率风险线索 | 不做全面漏洞扫描或攻击源归因；自然风险确认/恢复仍需现场对象 |

本地样例和测试可以覆盖故障恢复、配置变化、风险等构造分支，不能代替实验网的真实事件。真实实验网中的应用级 iperf3、不同配置快照、自然故障/风险恢复和课程验收粒度仍有未验证事项。
