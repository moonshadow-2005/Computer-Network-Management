# 五项管理功能使用说明

在 `project` 目录安装依赖后运行 `python run.py`，打开终端给出的本机地址。默认样例模式适合演示查询和理解数据；管理操作需要 live 模式下的配置与令牌。

## 本地样例操作

| 功能 | 操作 | 预期结果 |
|---|---|---|
| 故障 | 设备筛选选 `sample-host-1` | 一条已恢复的样例告警和五条 ping 历史，包括丢包与恢复 |
| 配置 | 快照设备选 `sample-router`，选择较早与较新快照，点击比较 | 接口描述由 `sample-ens2` 变为 `sample-ens3`，新增一条样例路由 |
| 性能 | 主机选 `sample-host-1`，接口选 `sample-router:1` | RTT/丢包趋势；一个无效首样本和一个有效速率样本，入/出为 100/200 bit/s |
| 计费 | 接口选 `sample-router:1`、双方向；输入北京时间 `2026-10-13 17:00:00` 至 `17:00:11` | 入 125、出 250 byte，覆盖率 90.91%，窗口不完整；CSV 两行与页面一致 |
| 安全 | 查看 `sample-host-1` 的服务基线、端口检查和风险 | TCP/5201 的样例基线不允许开放，样例观测为开放，出现相应风险 |

时间输入按浏览器所在电脑的本地时区转换为 UTC；上述时间例子要求本地时区为 UTC+8。样例 `sample-iperf-1` 是预置任务，不会启动吞吐量测试。

## 来源和结果状态

- `document`：文档导入的候选清单或逻辑关系，不能当作实时发现。
- `sample`：构造演示数据。
- `live`：实际执行的采集或检查；仍须结合状态、错误和采样时间判断结果。
- `configured`：手工设定的服务基线，表示预期而非观测。

缺值用未知或空值表示。接口参考速率未知时，方向速率可以有效而利用率为空。无效区间保留原因，不会在趋势图中连接成正常数据。

## 实验模式操作

启动 `python run.py --mode live` 后，在“运行与采集”区域填写本机 `NMS_API_TOKEN` 对应的管理令牌。令牌仅用于当前页面，不保存到浏览器持久存储。

1. 点击“执行一轮只读采集”，等待完成后查看新增运行编号、开始/结束时间和各目标状态。右上角“刷新数据”只重新读取已有数据。
2. 在故障管理选择设备，查看事件及 ping 证据；“确认告警”记录已知悉时间，事件是否恢复仍由后续观测决定。
3. 在配置管理查看接口和路由，选择同设备的两份不同快照比较。只有一份快照时比较按钮禁用。
4. 在性能管理查看主机 RTT/丢包和接口方向速率；样本间隔过长等情况会保留无效原因。
5. 在计费管理选择接口、方向、起止时间，核对字节量、覆盖率和缺口，再下载同窗口 CSV。只累计窗口内完整有效区间，不对缺失时间外推。
6. 在安全管理设置目标端口的预期状态和说明，再按需检查该端口；端口探测需单独启用。`unavailable` 表示未知，不能当作关闭。

## iperf3 与安全风险

网页默认发起 2 秒、10 Mbit/s 的 iperf3 任务；API 范围为 1～3 秒、最多 10 Mbit/s。两端必须是登记的不同测试主机，运行中的任务可以取消。同一端点被占用时不会并发复用。

启用任务前须完成服务账户的 SSH 密钥、严格主机密钥校验和两端工具准备，详见[实验配置](实验环境配置.md)。关闭功能时返回 503，此响应只说明功能不可用。

安全模块依据服务基线和连续高利用率形成风险线索。风险确认表示已知悉，恢复表示后续观测满足恢复条件；风险记录不直接证明漏洞或攻击源。

## 常见问题

| 现象 | 检查方向 |
|---|---|
| 找不到 Python 模块 | 确认在 `project` 目录、使用安装依赖的同一个解释器 |
| 8000 已占用 | `python run.py --port 8001`，按新地址访问 |
| 页面只有候选清单 | 实验库尚无成功采样；本地演示应使用默认 demo 模式 |
| 页面数据不再增加 | `NMS_POLL_INTERVAL=0` 时不自动采集；刷新页面只读库 |
| 写请求 401 | 管理令牌不匹配 |
| 写请求 503 | 令牌未配置或对应功能未启用，查看具体消息 |
| 计费不完整 | 查看无效区间、覆盖率；选择有连续有效相邻样本的窗口 |
| Windows 上旧库迁移被拒绝 | 迁移备份要求可验证的私有文件权限；实验库迁移在支持 Unix 权限的 Linux 文件系统进行 |
