# 五项管理功能使用说明

2026-10-20 更新：功能分视图、长表分页、最新地址与历史分开、30 秒自动刷新、告警业务背景、北京时间输入和本机自动授权。截图已同步至新版[图文教程](图文使用教程.md)。

首次使用可先阅读[图文教程](图文使用教程.md)，或打开同目录的[独立 HTML](图文使用教程.html) / [PDF](图文使用教程.pdf)。教程逐步解释实际页面截图及预期结果。

真实环境的 SSH 转发、两种 live 使用路线、配置文件与手动采样步骤，见[项目 README](../README.md)的“真实环境 live：访问与启动”和图文教程第 12 节。

在 `project` 目录安装依赖后运行 `python run.py`，打开终端给出的本机地址。默认样例模式适合演示查询和理解数据；本地修改样例使用 local 模式，真实采集使用 live 模式，两者的管理操作均需要令牌。

## 一键打开真实网页

**当前这台维护电脑：**在 Windows 文件资源管理器打开 `C:\Myfiles\Mycode\2026\计网管`，双击 **`一键打开网络管理网页.cmd`**。`大作业\project` 中也有 **`一键打开真实网页.cmd`**，两个入口效果相同。

1. 启动器检查端口和现有连接；连接正常时直接复用。
2. 尚未就绪时，连接原有 WARP 代理模式，使用本机配置与加密凭据建立 DEV 通路。
3. 网页及管理员授权检查通过后，自动打开 `http://127.0.0.1:8000/`。
4. 顶部显示“本机管理员已连接”，无需手动输入 token；成功后启动窗口可关闭。

这是 Windows 双击入口，不是 Bash 脚本。重启电脑后再次双击，无需另开 WSL 启动 Python。关闭网页不关闭后台连接；关闭本机连接可在 PowerShell 运行 `project\deploy\stop_windows_loopback_tunnel.ps1`，不会停止 DEV 后台。

| 提示 | 处理 |
|---|---|
| 另一个启动器正在建立连接 | 等待原窗口完成，避免反复双击 |
| 端口 8000 或 18080 已占用 | 关闭自己之前启动的样例服务或旧转发后重试；启动器不会停止陌生进程 |
| WARP 模式不匹配或无法连接 | 打开 WARP 检查后台服务，恢复本组原有 WarpProxy / 40000 配置 |
| 无法读取本机加密凭据 | 使用已配置的 Windows 账户，或先完成该电脑的自动授权配置 |
| 缺少本机连接文件 | 新电脑需要配置 SSH、固定主机密钥和课程认证资料，不能只复制启动器 |
| 通路建立失败或授权未通过 | 检查 WARP、DEV 可达性、课程登录资料；DEV token 变更后更新本机密文 |

失败窗口保留提示，按任意键关闭。启动器使用相对路径，项目整体搬迁后应保留目录结构；Windows 账户内的加密凭据仍按账户读取。

## 新版导航与刷新

首页只展示概览和入口，点击顶部导航切换功能；地址可直接使用 `/#fault`、`/#config`、`/#performance`、`/#accounting`、`/#security`、`/#operations`。功能切换保留表单；进入告警详情则打开独立页面。

普通长表每页 10 行。性能样本、故障 ping 历史、拓扑等明细需要展开；界面标注已载入数量，部分列表只查询最近记录，完整记录可通过 API 的 limit/offset 查询。地址历史提供服务器分页。

默认每 30 秒重新读取数据；后台标签页、输入框编辑中或上一轮刷新未完成时跳过。可取消勾选改为手动。自动刷新不启动采集，保留未保存表单及快照比较。顶部显示视图更新时间，真实新鲜度看采样时间及采集轮次。

“待处理风险”只统计 open；概览另列包含 acknowledged 的未解除风险。接口状态告警显示接口名称并提示业务影响待确认，特别是 virbr0 等接口，不能单凭状态判断业务中断。

配置的地址默认取各设备最新一次发现，不回退旧成功记录；失败和部分读取须看“最近地址发现状态”。展开历史地址可按设备查询。接口和路由保留各自最近观测/最后完整成功结果，注意逐行时间。

性能和计费初次打开优先选运行中的非回环、非常见虚拟候选接口；仍需自己核对业务接口。计费默认最近 15 分钟，支持最近 1 小时；快捷按钮只填入时间，点击统计才查询。样例练习需改成下表的历史时间。

## 管理授权

通过已配置加密凭据的本机入口访问 DEV 时，顶部显示“本机管理员已连接”，可直接执行管理操作；主页和详情页会自动使用本机授权，不需要填写令牌。浏览器刷新、跳转和重新打开页面后都会重新检查授权。直接 SSH 转发、未配置的电脑及本地样例仍保留手动输入方式。

## 本地样例操作

| 功能 | 操作 | 预期结果 |
|---|---|---|
| 故障 | 设备筛选选 `sample-host-1` | 一条已恢复的样例告警和五条 ping 历史，包括丢包与恢复 |
| 配置 | 快照设备选 `sample-router`，选择较早与较新快照，点击比较 | 接口描述由 `sample-ens2` 变为 `sample-ens3`，新增一条样例路由 |
| 性能 | 主机选 `sample-host-1`，接口选 `sample-router:1` | RTT/丢包趋势；一个无效首样本和一个有效速率样本，入/出为 100/200 bit/s |
| 计费 | 接口选 `sample-router:1`、双方向；输入北京时间 `2026-10-13 17:00:00` 至 `17:00:11` | 入 125、出 250 byte，覆盖率 90.91%，窗口不完整；CSV 两行与页面一致 |
| 安全 | 查看 `sample-host-1` 的服务基线、端口检查和风险 | TCP/5201 的样例基线不允许开放，样例观测为开放，出现相应风险 |

时间显示及输入均固定为北京时间（UTC+8），提交后转换为 UTC，与浏览器所在时区无关。样例 `sample-iperf-1` 是预置任务，不会启动吞吐量测试。

## 本地交互测试

默认 demo 模式主动关闭管理写入，点击“确认告警”等按钮返回 503。要测试这些操作，先按 `Ctrl+C` 停止旧服务，在 WSL 的 `project` 目录运行：

```bash
NMS_API_TOKEN=local-test-only python3 run.py --mode local --port 8001
```

打开 `http://127.0.0.1:8001/` 并刷新页面，在导航“运行 → 管理令牌”填写 `local-test-only`。此值仅是本机测试示例，正式部署应自行设置令牌。

| 操作 | 通过标准 |
|---|---|
| 故障筛选选择 `sample-host-1`，点击“确认告警” | 显示“已确认”和确认时间；原 `recovered` 状态保留，刷新后仍已确认 |
| 在安全管理进入样例风险的“查看详情”，填写令牌后确认；也可展开按编号快速确认 | 状态由 `open` 变成 `acknowledged`，记录来源仍为 `sample` |
| 安全管理选择 `host-1`、TCP/22、预期开放“是”，说明填“本地表单测试”，点击“保存基线” | 表格出现相应基线，切换对象再切回时回填“是”和说明；只保存设置，不连接主机 |
| 清空或填错页面管理令牌后尝试保存基线 | 清空时页面提示填写；填错时请求返回 401，原保存内容不变；恢复正确令牌可继续操作 |
| 查看实际采集、检查端口或开始 iperf3 按钮 | 按钮置灰并说明当前未启用；不执行真实网络操作 |

local 使用独立的 `data/local-test-v3.sqlite3`，默认不使用 `NMS_DB` 指向的实验库。测试修改会保留；若想从新样例开始，可用 `--db data/local-test-round2.sqlite3` 指定一个未使用过的文件名。

## 告警与风险详情

“故障”和“安全”视图只显示证据摘要。点击对应记录的“查看详情”，进入独立页面：

- 故障告警：`/events/编号`，查看设备、状态、首次与最近观测、恢复及确认时间；关联证据每页 20 条，可翻页查看原始 ping 或接口状态样本。缺失样本会明确提示。
- 安全风险：`/risks/编号`，查看规则、级别、生命周期、全部已保存证据及建议；下方可展开原始 JSON。
- 详情页的“返回主页”回到对应功能区域。“刷新详情”重新读取当前记录；查看和翻页不会触发采集或自动确认。
- 可以在详情页填写管理令牌并确认当前记录；令牌不持久保存。确认表示已知悉，故障恢复及风险解除仍取决于有效观测。

## 来源和结果状态

- `document`：文档导入的候选清单或逻辑关系，不能当作实时发现。
- `sample`：构造演示数据。
- `live`：实际执行的采集或检查；仍须结合状态、错误和采样时间判断结果。
- `configured`：手工设定的服务基线，表示预期而非观测。

缺值用未知或空值表示。接口参考速率未知时，方向速率可以有效而利用率为空。无效区间保留原因，不会在趋势图中连接成正常数据。

## 实验模式操作

启动 `python run.py --mode live` 后，在“运行与采集”区域填写本机 `NMS_API_TOKEN` 对应的管理令牌。手动令牌仅用于当前文档，不保存到浏览器持久存储；本机自动授权入口无需手动输入。

1. 点击“执行一轮只读采集”，等待完成后查看新增运行编号、开始/结束时间和各目标状态。右上角“刷新数据”只重新读取已有数据。
2. 在故障管理选择设备，查看事件及 ping 证据；“确认告警”记录已知悉时间，事件是否恢复仍由后续观测决定。
3. 在配置管理查看接口和路由，选择同设备的两份不同快照比较。只有一份快照时比较按钮禁用。
4. 在性能管理查看主机 RTT/丢包和接口方向速率；样本间隔过长等情况会保留无效原因。
5. 在计费管理选择接口、方向、起止时间，核对字节量、覆盖率和缺口，再下载同窗口 CSV。只累计窗口内完整有效区间，不对缺失时间外推。
6. 在安全管理设置目标端口的预期状态和说明，再按需检查该端口；端口探测需单独启用。`unavailable` 表示未知，不能当作关闭。

## iperf3 与安全风险

网页默认发起 2 秒、10 Mbit/s 的 iperf3 任务；API 范围为 1～3 秒、最多 10 Mbit/s。两端必须是登记的不同测试主机，运行中的任务可以取消。同一端点被占用时不会并发复用。

启用任务前须完成服务账户的 SSH 密钥、严格主机密钥校验和两端工具准备，详见[实验配置](实验环境配置.md)。页面会根据运行状态将未启用的真实测试按钮置灰；直接调用关闭的 API 时仍返回 503。管理令牌只用于身份校验，不会开启这些网络功能。

安全模块依据服务基线和连续高利用率形成风险线索。风险确认表示已知悉，恢复表示后续观测满足恢复条件；风险记录不直接证明漏洞或攻击源。

## 常见问题

| 现象 | 检查方向 |
|---|---|
| 找不到 Python 模块 | 确认在 `project` 目录、使用安装依赖的同一个解释器 |
| 8000 已占用 | `python run.py --port 8001`，按新地址访问 |
| 页面只有候选清单 | 实验库尚无成功采样；本地演示应使用默认 demo 模式 |
| 页面数据不再增加 | `NMS_POLL_INTERVAL=0` 时不自动采集；刷新页面只读库 |
| 启动样例时报备份权限错误 | 默认启动器现使用 `data/demo-v3.sqlite3`，保留旧 `demo.sqlite3` 并重新生成样例；更新代码后用 `python run.py` 启动，无需删除旧库。显式 `--db` 指定的旧库仍需在支持 Unix 私有权限的文件系统迁移 |
| 写请求 401 | 在“运行与采集”填写与启动服务的 `NMS_API_TOKEN` 相同的值；刷新或重新打开页面后需重新填写。local 示例启动命令对应 `local-test-only` |
| demo 中“确认告警”等写操作返回 503 | 改用上述 local 模式并设置、填写同一个管理令牌 |
| 写请求 503 | 令牌未配置或对应功能未启用，查看具体消息 |
| 计费不完整 | 查看无效区间、覆盖率；选择有连续有效相邻样本的窗口 |
| Windows 上旧库迁移被拒绝 | 迁移备份要求可验证的私有文件权限；实验库迁移在支持 Unix 权限的 Linux 文件系统进行 |
